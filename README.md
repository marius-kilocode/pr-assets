# assets branch

This orphan branch hosts screenshots that are referenced in pull request descriptions and comments across repos.

Images are uploaded via the GitHub Contents API and referenced as:

```html
<img width="700" alt="description" src="https://github.com/marius-kilocode/pr-assets/blob/assets/<filename>.png?raw=true" />
```

Everything here is publicly visible. Never upload screenshots containing secrets, tokens, emails, or private data. Do not merge this branch into `main`.
